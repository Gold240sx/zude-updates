# Zude updates

Zude's update feed for Sparkle: `appcast.xml`, served at https://gold240sx.github.io/zude-updates/appcast.xml, and
each release's app, signed with Zude's update key and notarized. `Scripts/release.sh <version> --publish` in Zude's
source repository writes and pushes it; nothing here is edited by hand.
